01 / BEYOND A SINGLE ACTION

从一次抓取，到完成一项工作

设想让机器人完成一项工作：“把散落的工具收好，再把需要的零件送到工位。”

这项任务包含识别、移动、抓取与放置。途中有人经过、工具位置发生变化，或第一次抓取没有成功，机器人都需要重新判断，并调整下一步行动。

一次成功的抓取，距离独立完成家庭整理、野外作业、产线装配仍有很长的路。

大模型擅长抽象指令，然而从信息到走向安全、可靠、可持续的具体操作运行，仍需要解决：当算力升级，如何兼顾快速适配与供能效率的问题。

HyperBrain Box 将安装、连接、供能与计算整合为统一平台，减少分散配置的软硬件环节，让开发团队更专注于模型适配与任务验证。

识别→移动→抓取→放置环境变化 → 重新判断 → 调整行动
02 / WHY HYPERBRAIN BOX

为什么需要 HyperBrain Box

多平台兼容，面向真实场景部署

不同任务需要不同形态的机器人，也对应着多样化的适配安装和外设配置。HyperBrain Box 通过快拆架设计，在适配平台上无需改造本体结构，支持分钟级拆装；丰富的 I/O 接口与车规级连接方案，为不同外设和任务配置提供扩展空间。

此外，它支持 45℃ 环境温度下持续满功率不降频运行，并针对水溅、粉尘等现场挑战进行防护设计，为持续运行提供保障。

分钟级拆装丰富 I/O 接口45℃ 持续满功率

性能增强，续航无损

HyperBrain Box 内置 340Wh 半固态电池，提供约 2 小时独立续航。无需取用机器人本体电量，即可为计算平台提供独立的能量来源，减少对本体供电系统的依赖。同时，支持边充边用，24V / 60W 的对外供电设计，可为常用功能外设供电，简化电源配置。

面对日常反复使用，HyperBrain Box 可实现在 400 次充放电后，健康状态仍不低于 80%，满足长期作业需求，更好用且更耐用。

支持边充边用24V / 60W 对外供电

强劲 AI 算力，端侧智能自主驱动

HyperBrain Box 搭载高算力芯片模组，提供最高 2070 TFLOPS（FP4）AI 算力与最高 128GB 统一内存，并提供多种配置选择，为大模型端侧推理、感知信息处理及任务规划提供计算支撑。
