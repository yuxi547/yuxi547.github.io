Introducing HyperBrain RSI-Preview: A General-Purpose, Self-Evolving Physical Agent Architecture

2026 / 11 / 17Hyperplane Robotics
Product launchTechnical insightsHyperBrain RSI

Hyperplane Robotics introduces HyperBrain RSI-Preview, a general-purpose, self-evolving physical agent architecture. Using the official evaluation scripts for the RoboDojo robot-learning benchmark, we completed local testing across 54 task configurations and 2,100 episodes. The overall score was 78.87, with a 73.50% success rate; memory and precision scores reached 96.17 and 91.08 respectively [1], comparable to NVIDIA SOLVE, the current leader on the agent leaderboard.

Beyond these results, we are focused on a longer-term question: can robots turn every task into a learning opportunity and continue to evolve as they operate?

CHAPTER 01

Giving Robots Their Own Flywheel for Continuous Improvement

Progress in embodied intelligence has long depended on manually collected demonstrations, which are costly and slow to scale. To overcome this bottleneck, robots need to learn from execution: accumulating experience as they complete tasks autonomously and continually converting that experience into greater capability.

Closing the loop from task execution to experience accumulation and capability growth is the starting point for HyperBrain RSI-Preview. We want every action to lay the groundwork for the next improvement.

CHAPTER 02

The Technology Behind the Results

HyperBrain RSI-Preview is built on Claude Opus 5.5, with no training or fine-tuning required throughout the process. Apart from the foundation model, we independently built the core modules, including the runtime loop, skill system, motion primitives, task memory and tool calls.

We focused on three areas to build this closed loop for physical agents:

01. Making Long-Horizon Task Execution More Reliable

Long-horizon tasks require more than execution: they also demand memory, reasoning and verification. Traditional end-to-end policies typically output actions directly, without intermediate verification. When deviations occur, they may go uncorrected and compound during subsequent execution. HyperBrain RSI-Preview addresses this with the following approaches:

a. Write programs instead of outputting actions directly

Generate executable programs for tasks, verifying and deciding each step based on actual outcomes. Stop and adjust immediately after failure, rather than continuing along a predetermined plan.

b. Measure in real time and actively verify the environment

The system relies solely on three RGB cameras for measurement. When a measurement is unreliable, it actively changes the viewpoint and measures again until it obtains trustworthy feedback.

In local RoboDojo tests, HyperBrain RSI-Preview scored 96.17 on memory, 91.08 on precision and 78.01 on long-horizon tasks. Of the 54 task configurations, 24 scored above 90.

The marker-placement task below shows HyperBrain RSI-Preview correcting its own errors without human intervention. It diagnoses the cause of failure and adapts its approach to complete the complex task successfully.

02. Using Resources on Demand for More Efficient Execution

A single large-model inference often takes several seconds, while a robot control cycle lasts only tens of milliseconds. If every action depends on a model decision, the time and monetary costs become too high for practical deployment.

HyperBrain RSI-Preview reduces costs in three ways:

a. Program-driven execution

Generate multi-step programs with fewer model calls.

The model generates programs rather than making decisions one step at a time. In a block-stacking task, the robot performed 515 actions with just 6 model calls.

b. Local state measurement

Measure state locally so reasoning can focus on decisions.

State information such as position is measured locally and returned as numbers. The model only needs to review the most recent observations, avoiding continuous growth of the context.

c. Cache reuse

Build each inference on existing results.

Prompts and conversation history are cached and reused together, reducing repeated computation and reserving more compute for problems that actually require reasoning.

Across 2,100 local RoboDojo episodes, model calls cost a total of US$1,219.51, or approximately US$0.58 per episode. This offers better cost efficiency than publicly reported per-episode costs of roughly US$1 to US$2.50.

The cost of improving capability is also manageable. With the foundation model unchanged, HyperBrain RSI-Preview improved its overall score from 38.9 to 78.87, while total model-call costs during development remained below US$2,000.

For both task execution and continued optimization, shorter waits and lower costs provide a practical foundation for long-term robot operation and large-scale task execution.

03. Turning Execution Feedback into Continuous Improvement

Being able to execute does not mean having learned. Capability truly grows only when feedback from a task can be retained and reused.

In HyperBrain RSI-Preview, an optimization agent automatically analyzes the execution logs after each batch of tasks, identifies causes of failure and writes the resulting lessons into task notes and tools. Each new version is compared with the previous version on the same layouts, and only changes that demonstrably improve performance are retained.

Experience therefore extends beyond any single task. A failure caused by an incorrect grasp pose, a missed step in a sequence or an incorrect state assessment is retained as a lesson, so that the next batch of tasks is less likely to repeat the same mistake.

The foundation model remains unchanged throughout. Only the readable, inspectable and continually improvable notes and code evolve.

Using the same foundation model, successive rounds of accumulated experience increased the average score from 38.9 for the initial version on training layouts to 78.87 for the final version on unseen test seeds.

In the build_tower task, for example, HyperBrain RSI-Preview iteratively improves task instructions and tools using execution logs. It adjusts gripper movements and wrist rotation, improves the transport process to avoid knocking over pillars, and then adds tools for placing planks and the roof. The final version scored 98.2 in an independent test, completing 49 of 50 layouts.

CHAPTER 03

What Comes Next for Embodied Intelligence

HyperBrain RSI-Preview provides initial evidence that robots can not only execute tasks, but also continually improve based on execution outcomes.

Reliable execution, manageable costs and accumulated experience are parts of the same closed loop. Capability can grow during operation only when tasks are completed reliably, feedback is continuously recorded and experience is retained. For embodied intelligence, this may offer a more sustainable path forward than simply increasing model size.

Hyperplane Robotics will continue developing this loop of execution, feedback and evolving experience, enabling robots to keep learning and improving through real tasks. We will share further progress as it unfolds. Next, we will put the system to the test in real-world scenarios.
