通用自进化物理 Agent 架构 HyperBrain RSI-Preview 正式发布

2026 / 11 / 17超平面机器人
产品发布技术分享HyperBrain RSI

超平面机器人推出通用自进化物理 Agent 架构 HyperBrain RSI-Preview。在机器人学习基准 RoboDojo 榜单上，我们用基准的官方评测脚本完成了本地测试：54 个任务配置、2100 局，综合得分 78.87，成功率 73.50%；其中记忆类 96.17，精度类 91.08[1] , 比肩当前 Agent 榜首英伟达 SOLVE。

成绩之外，我们关注更长远的问题：机器人能否将每一次任务转化为学习机会，并在持续执行中不断进化。

CHAPTER 01

让机器人拥有属于自己的进化飞轮

具身智能的能力提升，长期依赖人工采集的示范数据，成本高、增长慢。要突破这一瓶颈，机器人需要学会从执行中学习，在自主完成任务的同时积累经验，并将经验持续转化为能力增长。

打通从任务执行到经验积累，再到能力增长的物理 Agent 工作闭环，正是 HyperBrain RSI-Preview 的出发点。我们希望，让每一次行动都为下一次进步创造条件。

CHAPTER 02

成绩背后的关键技术支撑

HyperBrain RSI-Preview 基于 Claude Opus 5.5 构建，全程无需训练或微调。除基础模型外，运行循环、技能系统、运动原语、任务记忆与工具调用等核心模块均由我们自主构建。

围绕这一物理 Agent 闭环，我们主要做了三件事：

01. 应对长程任务，让行动更可靠

长程任务考验的不只是执行能力，还包括记忆、推理与验证能力。传统的端到端策略通常直接输出动作，缺乏中间验证机制。一旦出现偏差，无法及时纠正，会导致后续执行中持续放大。针对于此，HyperBrain RSI-Preview 采用以下方法：

a. 写程序，而非直接输出动作

将任务生成可执行程序，每一步都基于真实结果验证与决策；失败立即停止并调整，而不是沿着预设计划持续执行

b. 实时测量，主动验证环境

系统仅依赖三台 RGB 相机完成测量，当测量结果不可靠时，会主动调整观察视角并重新测量，直至获得可信反馈

在 RoboDojo 本地测试中，HyperBrain RSI-Preview 取得了记忆类 96.17、精度类 91.08、长程类 78.01 的成绩；54 个任务配置中，24 个得分超过 90。

通过下面将马克笔放入笔筒的任务，可以发现，在无人干预的情况下，HyperBrain RSI-Preview 自主进行纠偏，并能够诊断失败原因，灵活改变操作方式，成功完成复杂任务。

02. 按需调用资源，让执行更高效

大模型一次推理往往需要数秒，而机器人的控制周期只有几十毫秒。如果每一步动作都依赖模型决策，时间成本和金钱成本太高，很难在实际中落地。

HyperBrain RSI-Preview 通过三种方式降低成本：

a. 程序驱动执行

少量调用，一次生成多步程序

模型负责生成程序，而非逐步决策。在叠积木任务中，机器人执行 515 个动作，模型仅调用 6 次

b. 状态本地化

状态信息本地测量，让推理聚焦决策

位置等状态信息在本地完成测量并以数字返回，模型只需查看最近几次观测结果，避免上下文持续膨胀

c. 缓存复用

让每次推理都建立在已有结果之上

提示词与历史对话统一缓存复用，减少重复计算开销，将更多算力用于真正需要推理的问题

在 2100 局 RoboDojo 本地测试中，模型调用总成本为 1219.51 美元，平均每局约 0.58 美元。相比目前市面上已公开单回合花费（约1 到 2.5 美元），性价比更高。

能力提升的成本同样可控，在基础模型保持不变的情况下，HyperBrain RSI-Preview 综合得分从 38.9 提升至 78.87，开发时调用的模型总成本不到 2000 美元。

无论执行任务还是持续优化，更少的等待时间和更低的花费成本，为机器人长期运行和大规模任务执行提供了现实基础。

03. 利用执行反馈，让能力不断成长

会执行并不等于学会。只有当一次任务中的经验反馈能够被沉淀和复用时，能力才会真正增长。

在 HyperBrain RSI-Preview 中，每完成一批任务，一个优化 Agent 会自动分析这一批执行日志，定位失败原因，并把得到的经验写入任务笔记和工具。新版本会在相同布局上与旧版本对比验证，只有确实带来提升的改动才会被保留。

因此，经验不会停留在单次任务里。某一次因为夹取姿态错误、顺序记忆遗漏或状态判断失误而产生的失败，会被沉淀下来，让下一批任务少犯一次同样的错误。

整个过程中基础模型保持不变，变化的只有这些可阅读、可检查、可持续迭代的笔记和代码。

在同一个基础模型下，经过多轮经验累积，系统的平均得分从初始版本在训练布局上的 38.9 提升到最终版本在未见测试种子上的 78.87。

以build_tower任务为例，HyperBrain RSI-Preview 会根据运行日志逐轮改进任务说明和工具：它调整夹爪动作与手腕旋转方式，并针对柱子被碰倒的问题改进搬运流程，随后新增放置木板和屋顶的工具。最终测试版本在独立测试中取得了 98.2 分，50 个布局中完成了 49 个。

CHAPTER 03

看见具身智能下一步

HyperBrain RSI-Preview 初步证明了：机器人不仅能够执行任务，也能够根据执行结果持续改进。

可靠执行、可控成本和经验积累并非彼此独立，而是构成同一个闭环。任务被稳定完成，反馈被持续记录，经验被不断沉淀，能力才能在运行中增长。对于具身智能而言，这或许是一条比单纯扩大模型规模更可持续的演进路径。

未来，超平面机器人将继续推进执行、反馈与经验演化的闭环建设，让机器人在真实任务中持续成长、持续进化。后续进展将陆续分享，下一步，我们将在真实场景中接受检验。
